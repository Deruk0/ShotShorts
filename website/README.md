# Сайт ShotShorts

Статический сайт приложения с описанием, условиями использования и политикой конфиденциальности. HTML и CSS не требуют установки зависимостей или сборки. На сайте нет форм загрузки, авторизации, аналитических скриптов и внешних шрифтов.

## Опубликованные адреса

- Главная: https://shotshorts.vercel.app/
- Условия использования: https://shotshorts.vercel.app/terms
- Политика конфиденциальности: https://shotshorts.vercel.app/privacy

Эти адреса проверены без авторизации: каждая страница возвращает HTTP 200 и содержимое ShotShorts. Служебные адреса деплоя и дополнительный адрес с именем аккаунта могут быть защищены входом Vercel, поэтому для TikTok используйте основной адрес `shotshorts.vercel.app`.

## Локальная проверка

Из корня репозитория:

```powershell
python -m http.server 4179 --bind 127.0.0.1 --directory website
```

Откройте `http://127.0.0.1:4179/`. Локальный сервер Python перенаправляет адреса разделов на вариант с завершающим слешем; опубликованный Vercel обслуживает `/terms` и `/privacy` напрямую.
