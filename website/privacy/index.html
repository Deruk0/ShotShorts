Политика конфиденциальности

Дата редакции: 19 октября 2026 года. Приложение: ShotShorts. Разработчик проекта: Deruk0. Контакт: GitHub Issues.

1. Область действия

Политика описывает фактические потоки данных настольного приложения ShotShorts и его информационного сайта. У приложения нет собственного облачного кабинета или сервера для хранения пользовательской медиатеки. Однако работа выбранных функций включает передачу данных сторонним сервисам; приложение не является полностью автономным.

2. Данные на вашем устройстве

  • Исходные видео и аудио, изображения, фоновые ролики, субтитры и результаты обработки в выбранных вами папках.
  • Промежуточные файлы: извлечённое аудио, фрагменты, транскрипты и данные рендера. Приложение пытается очищать временные файлы после обработки; при сбое часть файлов может сохраниться.
  • Настройки, пути, пресеты, выбранные модели и провайдеры, ключи AI-провайдеров, конфигурация прокси и локальная статистика работы.
  • Планы TikTok: имя аккаунта, пути к роликам, описания, время, разрешения, статусы и идентификаторы отправок.
  • При подключении TikTok API — ключи приложения, токены доступа и обновления; при использовании Studio — отдельный локальный профиль Edge с данными сеанса TikTok.

Нужные данные сохраняются для обработки материалов, восстановления настроек, подключения выбранных сервисов и исполнения ваших поручений по публикации. Не все локальные настройки зашифрованы: в частности, ключи AI-провайдеров и параметры прокси необходимо защищать средствами доступа к вашему устройству.

3. Передача выбранным AI-сервисам

При запуске транскрибации аудио отправляется выбранному вами Whisper-совместимому провайдеру. Для поиска историй и анализа сцен приложение отправляет соответствующие фрагменты текста и инструкции выбранному LLM-провайдеру. При использовании цепочки резервных моделей данные могут быть переданы следующему провайдеру в настроенном списке.

Адреса, ключи и модели задаёт пользователь. У каждого провайдера свои правила обработки, хранения, безопасности и использования данных. До отправки приватных материалов изучите его условия. Разработчик ShotShorts не определяет сроки хранения данных на серверах выбранного вами провайдера.

4. TikTok и публикации

При авторизации через TikTok API платформа выдаёт приложению разрешённые пользователем токены. Для подготовки публикации приложение получает данные профиля и доступные настройки аккаунта. При отправке в TikTok передаются выбранное видео, описание, видимость, разрешения и другие указанные параметры. Для проверки результата используются идентификатор и статус отправки.

При использовании браузерного расписания данные передаются непосредственно через сайт TikTok Studio в отдельном профиле Edge. Учётные данные для входа вводятся в интерфейсе TikTok, а состояние сеанса хранится браузером. Не передавайте файлы этого профиля посторонним.

TikTok самостоятельно обрабатывает полученные данные согласно своей политике конфиденциальности и правилам платформы. Удаление локальной записи очереди не удаляет опубликованное или запланированное видео из TikTok.

5. Другие сетевые обращения

Интерфейс и модуль оформления приложения могут загружать шрифты из Google Fonts и сохранять их в локальный кеш. Такие обращения передают сервису обычные технические сведения о соединении, включая IP-адрес. Если вы настроили прокси, сетевые запросы соответствующих функций проходят через него и подчиняются правилам выбранного оператора.

Обращения в GitHub, переходы по внешним ссылкам и скачивание выпусков обрабатываются соответствующими площадками по их политикам.

6. Информационный сайт

Этот сайт содержит статические страницы и не принимает видео, API-ключи, пароли или обращения через форму. На нём нет добавленных разработчиком рекламных трекеров, аналитических скриптов или собственного механизма cookies.

Хостинг Vercel получает технические данные HTTP-запросов, например IP-адрес, время запроса, запрошенный адрес и сведения о браузере, необходимые для предоставления и защиты сайта. Обработка таких данных регулируется политикой Vercel. Сторонние сайты, открываемые по ссылкам, могут использовать собственные cookies и аналитику.

7. Хранение и защита

Настройки и очередь сохраняются в каталоге данных приложения до их изменения или удаления пользователем. Готовые видео находятся в выбранной папке до удаления пользователем. Токены TikTok API хранятся отдельно, в файле tiktok-credentials.enc, с шифрованием через защищённое хранилище операционной системы. Эта защита не распространяется автоматически на остальные файлы настроек, медиатеку и резервные копии.

Профиль Edge хранит свои данные средствами браузера. Защитите учётную запись ОС, устройство и резервные копии. Абсолютная безопасность хранения или передачи данных не гарантируется.

8. Отключение и удаление данных

  • Чтобы прекратить отправку новым провайдерам, удалите их ключи и настройки из приложения.
  • Чтобы отключить Direct Post, используйте кнопку отключения аккаунта в приложении; она запрашивает отзыв доступа TikTok и удаляет локальные токены при успешном ответе. Разрешения также можно отозвать в настройках подключённых приложений TikTok.
  • Чтобы удалить сеанс Studio, выйдите из TikTok в отдельном окне Edge и очистите соответствующий профиль браузера после закрытия приложения.
  • Чтобы удалить локальные планы, настройки и кеши, закройте приложение и удалите соответствующие данные из его каталога. Файлы очереди и профиля Studio называются tiktok-queue.json и tiktok-studio-profile. Не удаляйте их во время загрузки.
  • Исходники, готовые ролики и резервные копии удаляются отдельно из выбранных папок. Опубликованные и запланированные материалы удаляются в TikTok. Запросы об удалении данных у AI-провайдеров направляются самим провайдерам.

9. Ваши обращения и права

Если применимое законодательство предоставляет вам права на доступ, исправление, удаление, ограничение обработки или возражение, вы можете обратиться к разработчику по вопросам данных, которые действительно находятся под его контролем. Данные, существующие только на вашем устройстве, разработчик не может получить или удалить удалённо.

Публичный контакт: GitHub Issues проекта. Не размещайте в открытом обращении токены, личные документы и медиа; сначала запросите подходящий конфиденциальный канал. Обработка у TikTok, Vercel, GitHub и выбранных AI-провайдеров регулируется также их собственными политиками и может происходить в странах работы этих сервисов.

10. Изменения политики

При изменении потоков данных или функциональности политика обновляется на этой странице. Дата действующей редакции указана в начале документа.
