## Что делает приложение

ShotShorts берет длинное видео или аудио, извлекает речь через FFmpeg, делает полный транскрипт через **Whisper-совместимую модель**, отправляет текстовые блоки в **LLM-анализ** для поиска отдельных историй, а затем рендерит вертикальные клипы **1080x1920** с субтитрами и фоновыми видео.

Модели подключаются универсально через **Custom AI Models** в настройках: подходит любой OpenAI-совместимый провайдер (Groq, OpenAI, локальные серверы и т.д.). Провайдер хранит общий Base URL и API ключ, а модели привязываются к нему — один ключ покрывает сколько угодно моделей. Для транскрибации и анализа собираются **цепочки фолбэков**: если модель упёрлась в лимиты или недоступна, следующая в цепочке подхватывает работу автоматически.

## Быстрый старт

### Требования

- Windows 10/11 x64
- Node.js 20+
- FFmpeg в `PATH` или `app/resources/ffmpeg.exe`
- Хоть одна OpenAI-совместимая ИИ-модель (транскрибация) и модель для анализа

### Установка

```bash
npm install
```

### Запуск Electron-приложения

```bash
npm run app:start
```

### Сборка Windows `.exe`

Для сборки с локальными ресурсами нужны `ffmpeg.exe` и `ffprobe.exe` в `app/resources/`.
Prebuild-проверка попробует автоматически скопировать их из `PATH`; если FFmpeg не установлен в системе, build остановится до упаковки, чтобы не получить exe, который падает уже у пользователя.

```bash
npm run app:build
```

Команда создаёт portable-файл `Ready_App_EXE/ShotShorts <version>.exe`.
То же самое можно запустить двойным щелчком по `build-portable.cmd` в корне проекта или по `Ready_App_EXE/Создать_EXE.bat`. Перед пересборкой приложение нужно закрыть.

Для быстрой папочной сборки без упаковки в единый файл используй:

```bash
npm run app:build:dir
```

Она создаёт `Ready_App_EXE/win-unpacked/ShotShorts.exe`. Все файлы в `Ready_App_EXE/` являются артефактами сборки и не хранятся в Git.

Если сборка специально должна полагаться на системный FFmpeg, можно запустить её с `SHOTSHORTS_ALLOW_UNBUNDLED_FFMPEG=1`, но такой билд уже не будет самодостаточным.

### Документация/сайт

```bash
npm run web:dev
```

## Использование

### Шаг 0. Подключи AI-модели

Без настроенных моделей генерация не запустится — приложение работает с любыми OpenAI-совместимыми провайдерами.

1. Открой вкладку **Settings → Custom AI Models**.
2. **Providers** — добавь провайдера: название, Base URL и API ключ. Например, для Groq укажи `https://api.groq.com/openai/v1` и ключ из [консоли Groq](https://console.groq.com/keys). Один провайдер = один ключ, к нему привязывается сколько угодно моделей.
3. **Models** — добавь модели, привязанные к провайдеру:
   - для транскрибации нужна Whisper-совместимая модель (endpoint `/audio/transcriptions`), например `whisper-large-v3`;
   - для анализа — любая чат-модель (Llama, GPT, Qwen и т.д.).
4. **Fallback chains** — собери цепочки для транскрибации и анализа: первая модель обрабатывает запрос, при rate limit или недоступности (429/401/403/404) автоматически подхватывает следующая. Порядок меняется стрелками ↑↓.
5. Выбери собранные цепочки в селекторах **Transcription** и **Analysis**.

### Шаг 1. Укажи пути

На вкладке **Generator**:

1. **Source Audio / Video** — исходное длинное видео или аудио (MP4, MP3, WAV и т.д.).
2. **Background Videos Folder** — папка с фоновыми вертикальными видео (ADHD-фон). Фоны берутся случайно, без повторов подряд.
3. **Output Folder** — папка, куда сохранятся готовые ролики.

### Шаг 2. Настрой субтитры и баннер (опционально)

- **Субтитры**: стиль (Classic, Minimal, Highlight, TikTok Bold, Heavy Shadow, Soft Box), шрифт, размер, регистр, количество слов в строке, караоке-подсветка. Позицию можно перетащить прямо в живом превью — фиксация по центру/краям работает автоматически.
- **Баннер**: фото или зацикленное видео поверх клипа; размер и позиция задаются drag-and-drop в превью. В режиме **Pause video & play banner with sound** ролик ставится на паузу каждые N секунд, проигрывается видео-баннер со своим звуком, затем контент продолжается с места паузы.

### Шаг 3. Запусти генерацию

Нажми **Generate**. Дальше всё автоматически:

1. FFmpeg извлечёт и подготовит аудио (длинные записи нарезаются на чанки).
2. Whisper-модель сделает транскрипт с таймкодами по словам.
3. LLM найдёт отдельные законченные истории и привяжет их границы к паузам транскрипта.
4. Приложение отрендерит вертикальные клипы 1080x1920 с субтитрами и фоном.

Прогресс, ETA и статистику рендера видно в интерфейсе. Готовые клипы появятся в выбранной папке вывода, временные файлы удаляются сами.

### Полезные настройки

- **App Language** — английский или русский интерфейс.
- **Presets** — быстрое переключение между сохранёнными наборами настроек.
- **Proxy** — HTTP/HTTPS/SOCKS5, если провайдер AI недоступен напрямую.

## Возможности

### AI и анализ

- Любые OpenAI-совместимые модели: транскрибация (Whisper-совместимый endpoint `/audio/transcriptions`) и чат-анализ
- Провайдеры с общим ключом: несколько моделей на один API ключ и Base URL
- Цепочки фолбэков для транскрибации и анализа: автоматическое переключение на следующую модель при rate limit или недоступности
- Двухэтапная проверка завязки и завершения каждой истории
- Привязка границ к блокам, словам и естественным паузам транскрипта
- Настраиваемая длина роликов в режиме историй: целевой диапазон (объединение коротких и нарезка длинных) и жёсткие границы (форс-слияние/нарезка крайних случаев); если безопасного разреза нет — история остаётся целиком
- Режим кино: длина сцены — только подсказка для ИИ (целевая/мин/макс), сильные сцены никогда не режутся; максимальное ограничение можно отключить полностью

### Субтитры

- Стили: Classic, Minimal, Highlight, TikTok Bold, Heavy Shadow, Soft Box
- Позиция: верх, центр, низ или свободное перетаскивание текста в живом превью с фиксацией по центру/краям
- Настройка шрифта, размера, регистра, отступа и количества слов в строке
- Караоке-режим с подсветкой слов
- Рендер через ASS/FFmpeg или Playwright overlay

### Видео

- Вертикальный формат 1080x1920
- H.264, 30fps
- Случайный ADHD-фон без повторов подряд
- Рекламный баннер: фото или зацикленное видео любого формата поверх клипа, позиция и размер через drag-and-drop превью
- Автоматический подбор и кеширование шрифтов
- Защита от зависания последнего кадра фонового видео

### Приложение

- Английский и русский интерфейс
- Пресеты настроек
- HTTP/HTTPS/SOCKS5 прокси
- Прогресс, ETA и статистика рендера
- Хранение настроек через `electron-store`

## Структура проекта

```text
ShotShorts/
├── app/                         # Electron-приложение
│   ├── main.js                  # Главный процесс Electron
│   ├── preload.js               # Безопасный мост IPC
│   ├── launch.js                # Запуск приложения
│   ├── renderer/                # HTML/CSS/JS интерфейс
│   └── services/                # Основная логика
│       ├── process-handler.js   # Оркестрация генерации
│       ├── media-processor.js   # FFmpeg обработка аудио и видео
│       ├── banner-utils.js      # Раскладка и overlay-фильтры рекламного баннера
│       ├── whisper-service.js   # Транскрибация через OpenAI-совместимый endpoint
│       ├── groq-story-analyzer.js # Анализ историй через выбранную LLM
│       ├── model-registry.js     # Реестр кастомных моделей (custom:<id>)
│       ├── groq-key-utils.js    # Нормализация ключей и cooldown
│       ├── subtitle-renderer.js # Рендер субтитров
│       ├── font-manager.js      # Загрузка и кеш шрифтов
│       ├── store.js             # Настройки и статистика
│       └── cleanup.js           # Очистка временных файлов
├── web/                         # Next.js сайт документации
├── .agent/                      # Агентские инструкции и шаблоны
├── .github/                     # CI/CD workflows
├── AGENT_FLOW.md                # Описание агентской архитектуры
├── CHANGELOG.md                 # История изменений
├── package.json                 # Workspaces и команды проекта
└── README.md
```

Сгенерированные папки вроде `node_modules/`, `Ready_App_EXE/`, `app/dist/`, `.next/`, `dist/` и `build/` игнорируются Git.

## Безопасность

- Не коммить API ключи моделей, `.env` файлы, тестовые аудио и локальные сборки.
- Если ключ случайно попал в репозиторий, сразу перевыпусти его у провайдера.
- Ключи добавляются через UI (Custom AI Models) и хранятся локально в `electron-store`.
