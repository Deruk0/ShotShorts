# Инструкции для работы с проектом

Перед изменениями прочитайте [.agent/README.md](.agent/README.md): там находятся карта проекта, команды и связанные проверки.

Ориентируйтесь на существующие файлы и актуальные `package.json`. При изменении архитектуры, команд или расположения модулей обновляйте карту проекта.

Проверяйте `git status` перед работой. Сохраняйте чужие изменения и удаления; не восстанавливайте удалённые файлы без необходимости для задачи.

Отвечайте на языке пользователя. Документацию и другие сохраняемые материалы пишите обычным, ясным языком.
